# BetterPetitPlanet

针对游戏《星布谷地》（Petit Planet）写的一个桌面辅助小工具，免费且开源。

项目的界面设计、截图捕获框架以及触发器机制主要参考了 [BetterGI (Better Genshin Impact)](https://github.com/babalae/better-genshin-impact)。目前主要做了两个功能：**自动拾取**（带 OCR 黑白名单过滤）和**自动演奏**。

## 目前支持的功能与已知限制

### 1. 自动拾取

- 基于 ONNX Runtime + DirectML 显卡加速运行本地 OCR，实时识别画面右侧的交互文字并自动按下拾取键。
- 采用类似 BetterGI 的 **OCR 黑白名单机制**：
  - **白名单（触发词）**：默认包含 `拾取`。
  - **黑名单（忽略词）**：默认包含 `拾取雪球`（防止在雪地跑图时把路边的雪球全捡起来）。
  - 支持在软件“自动拾取”页面自由添加或删除黑白名单关键词。

### 2. 自动演奏与原生悬浮谱面（竖笛）

- 自动识别游戏是否处于竖笛演奏界面，加载本地 JSON 曲谱自动按键演奏。
- **纯原生下落式悬浮谱面（Native Music Overlay）**：基于 WPF 原生高性能渲染引擎，零外部浏览器子进程，无需 WebView2，内存占用极低。
- 支持自动演奏模式（F9）与纯看谱跟弹模式（Ctrl+F9），支持 F10/F11 切歌与 Ctrl+F12 谱面显隐切换。
- 支持播放速度倍率调节（0.5x - 2.0x）、下落时长微调、视觉偏移校准、单曲循环、列表顺序播放与随机播放。

### 3. 当前已知限制（使用前请留意）

- **分辨率限制**：目前所有的图像识别区域（ROI）和乐器模板匹配**仅在 2K（2560x1440）分辨率下测试通过**，1080P、4K 等其他分辨率暂未充分测试，可能会出现识别不准的情况。
- **前后台限制**：受游戏客户端输入机制限制，目前的按键模拟需要游戏窗口处于前台激活状态才能稳定生效（关于前后台图像捕获与按键模拟的详细测试记录与对比表，可参阅 [前后台捕获与输入尝试复盘](docs/archive/capture-and-input-attempts.md)）。

## 用户使用指南（非开发者）

如果你只是想直接用这个工具，**不需要安装任何开发环境**，按下面几步操作即可：

1. 前往本仓库的 [Releases 页面](https://github.com/Sonder9999/better-petit-planet/releases)，下载最新版本的 `.zip` 压缩包（压缩包内已经直接包含了主程序、OCR 模型文件以及两首默认曲谱《One Last Kiss》和《稻香》）。
2. 将压缩包解压到任意文件夹。
3. 右键 `BetterPetitPlanet.exe`，选择**以管理员身份运行**（如果不给管理员权限，Windows 系统会拦截程序向游戏窗口发送的模拟按键）。
4. 先启动《星布谷地》并进入游戏画面，然后在工具主页点击**启动**按钮开启截图器。
5. 使用功能或快捷键控制：
   - **自动拾取**：默认按 `F8` 随时开关，开启后走到可拾取物品旁会自动按 `F`。
   - **自动演奏**：在游戏里拿出竖笛打开吹奏界面后，在软件“自动演奏”页选好曲子，按 `F9` 即可开始或停止自动演奏。
   - **跟弹模式**：按 `Ctrl+F9` 仅启动/暂停谱面时间轴，屏幕出现下落音符供手动跟弹练习，不自动发送按键。
   - **悬浮谱面显隐**：按 `Ctrl+F12` 快速显示或隐藏悬浮谱面。
   - **曲目切换**：按 `F10` 切换到上一首，按 `F11` 切换到下一首（所有快捷键均可在“快捷键”页面自定义与校验冲突）。

## 开发者说明（源码编译）

如果你想拉取源码自己修改或本地编译：

### 1. 需要额外下载的文件

克隆源码后，请前往 [Releases 页面](https://github.com/Sonder9999/better-petit-planet/releases) 下载单独上传的以下三个附件，并放到本地项目的对应相对路径下：

- `ch_PP-OCRv3_rec_infer.onnx`（约 10MB） -> 放入 `BetterPetitPlanet/Assets/Models/Ocr/ch_PP-OCRv3_rec_infer.onnx`
- `one_last_kiss.json` 与 `dao_xiang.json` -> 放入 `data/songs/recorder/` 目录下

### 2. 环境要求与编译文档

本项目完全基于纯原生 **.NET 8.0 (`net8.0-windows10.0.22621.0`)** 开发，**不依赖 Node.js、Bun 或 WebView2 运行时**。关于开发环境安装、依赖库说明、单元测试以及 Release 打包脚本的详细流程，请查阅 `docs/` 目录下的独立文档：

- [开发环境配置与源码构建指南](docs/development/environment-setup.md)
- [编译与发布流程](docs/development/build-and-release.md)
- [项目完整技术文档索引 (docs/)](docs/README.md)
