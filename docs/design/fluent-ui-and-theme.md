# Fluent UI 视觉规范与暗色主题

BetterPetitPlanet 客户端界面遵循微软 Windows 11 Fluent Design 设计哲学，基于开源库 `Wpf.Ui` 构建现代化、克制且一致的桌面交互体验。

---

## 1. 配色体系与主题层次

应用程序整体采用现代化暗色（Dark Theme）基调，强化视觉聚焦与游戏工具的沉浸感：

- **主窗体背景**：`#1C1F26`，沉稳的深石墨灰色调，避免纯黑带来的刺眼反差。
- **卡片容器底色**：`#0D1117` 与动态主题画刷 `ApplicationBackgroundBrush`。
- **重叠卡片与高亮层**：`#21262D`，用于次级分组、输入框底色与下拉菜单浮层。
- **主强调色（Accent Color）**：继承 Windows 系统主题色，并配备默认天蓝色（`#38BDF8`）与星空金（`#FFB900`），用于关键按钮、操作指示与超链接。
- **文本颜色层次**：
  - 主要标题与正文：`#FFFFFF` / `TextFillColorPrimaryBrush`，不透明度 100%。
  - 次要说明与辅助提示：`#E2E8F0` / `TextFillColorSecondaryBrush`，不透明度 80% - 90%。
  - 弱提示与禁用状态：`TextFillColorTertiaryBrush`，不透明度 50% - 60%。

---

## 2. 圆角规范（CornerRadius）

界面中所有 UI 元素严格遵循统一的圆角尺度，避免圆角风格混乱：

- **主卡片与 Banner 容器**：统一设定为 `CornerRadius="8"`。
- **标准交互控件（按钮、文本框、下拉选择器）**：统一设定为 `CornerRadius="6"`（在 `App.xaml` 中通过 `ControlCornerRadius` 资源统一管理）。
- **微型标签、徽标与状态指示点**：统一设定为 `CornerRadius="3"` 或 `CornerRadius="4"`。

---

## 3. 卡片式层次布局（Card Architecture）

主界面（HomePage）与各功能页面采用标准的分块卡片设计（CardExpander 与 CardControl）：

```text
+--------------------------------------------------------------+
| 顶部官方主视觉 Banner 卡片 (流式三层图层，高度 200，圆角 8)      |
+--------------------------------------------------------------+
| 截图器启动卡片 (CardExpander, 可折叠, 包含截图模式与推理设置)  |
+--------------------------------------------------------------+
| 同时拉起游戏卡片 (CardExpander, 包含游戏路径与 Unity 启动参数) |
+--------------------------------------------------------------+
| 桌面分身 / 后台运行卡片 (CardControl, 快速直达运行模式)       |
+--------------------------------------------------------------+
```

### 设计原则
- **渐进式披露（Progressive Disclosure）**：高阶或生僻配置默认折叠在卡片内部，主界面仅外露启动主按钮与状态描述，降低初次上手认知负荷。
- **视觉呼吸感**：页面外侧留有 `Margin="42,16,42,12"` 的充裕安全距离，各卡片间距保持 `Margin="0,0,0,12"` 的垂直节奏。
